# Income Estate — Real Estate Investment Portal

A high-converting, enterprise-grade Real Estate Investment Portal built with Next.js 15 (App Router), TypeScript, and Tailwind CSS. Tailored for NRI and high-ROI fractional/institutional real estate investments.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router & React Server Components)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict typing, zero `any`)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend / CMS Ready**: Payload CMS & Headless WordPress / WPGraphQL architecture

---

## 🛠️ Getting Started

### 1. Prerequisites

- Node.js 18+ or 20+
- npm, yarn, or pnpm

### 2. Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/Dev-9929/Income-Estate.git
cd Income-Estate
npm install
```

### 3. Environment Variables

Create a `.env.local` file based on `.env.example`:

```bash
cp .env.example .env.local
```

### 4. Running Locally

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
